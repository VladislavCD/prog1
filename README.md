# WorkshopTracker / Состояние изделий цеха 43

Настольное WPF-приложение под Windows для просмотра, поиска и анализа изделий по ежедневным листам Excel-таблицы отслеживания.

## Что реализовано в каркасе MVP

- безопасный импорт `.xlsx` через временную копию без изменения исходного файла;
- локальный SQLite-кэш с таблицами снимков изделий, входящих элементов, журнала импорта и FTS5-индексом;
- резервная копия предыдущего SQLite-кэша перед обновлением;
- первичное распознавание строк Excel с уровнем уверенности и ссылкой на файл, лист, строку и диапазон ячеек;
- журнал предупреждений по нераспознанным/сомнительным строкам;
- современный WPF-интерфейс: боковая панель, поиск, список изделий, карточка изделия, журнал ошибок импорта;
- офлайн-архитектура: Excel — источник данных, SQLite — локальный кэш, приложение — поиск и анализ.

## Стек

- .NET 8 WPF (`net8.0-windows`)
- ClosedXML для чтения Excel без Microsoft Excel и COM-автоматизации
- Microsoft.Data.Sqlite / SQLite FTS5 для локального кэша и поиска

## Защищённые книги Excel

Приложение читает Excel только в режиме чтения. Книги с паролем **на запись/изменение** поддерживаются: исходный файл копируется во временный read-only файл и не изменяется. Если пароль требуется **на открытие** книги, файл зашифрован, и его нужно открыть/сохранить без пароля на открытие перед импортом.

## Запуск

```powershell
dotnet restore
dotnet build .\WorkshopTracker.sln
dotnet run --project .\src\WorkshopTracker.App\WorkshopTracker.App.csproj
```

Для самодостаточной Windows-сборки:

```powershell
dotnet publish .\src\WorkshopTracker.App\WorkshopTracker.App.csproj -c Release -r win-x64 --self-contained true
```
